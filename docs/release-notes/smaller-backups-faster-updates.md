Fixed: Backups take far less room and updates install faster
Every backup held a full copy of the server's code and build files, which each update downloads again anyway, so one backup was about 437 MB and making it took close to three minutes of every update. Backups now keep only what you made (settings, customs, areas, cheats, drop tables, add-ons and the rest), so they are a few MB and are made in seconds. Older backups are made small once in the background the next time Ahziael opens, with everything you made still in them, and half-made backups left by a closed Ahziael are cleared. A second backup is no longer made right after an update when one was already made that day.
Where: Server > Ahziael > Backups, and the Documents\Ahziael backups folder.
Test: Note the size of the Documents\Ahziael backups folder, open Ahziael and wait a minute: the older backups shrink. Click Back up now and check the new one is small, then Restore it with the server stopped and check your customs and settings are still there. Update Ahziael and see it reopen much sooner.
