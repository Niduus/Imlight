New: Backups of everything you made
Ahziael now saves a backup of your settings, customs, areas, cheats, drop tables, Crown Shop, events, codes, overlay designs, add-ons and its own settings, plus every account and character while the server is stopped. Backups go to Documents\Ahziael backups, outside Ahziael's folder, so an uninstall or a broken install can't take them along. One is made by itself each day Ahziael opens and before every update. You can also click Back up now, and Restore any of them (a backup of how things are now is made first).
Where: Server > Ahziael
Test: Open Server > Ahziael, find Backups, stop the server and click Back up now. Then click Show beside it and check the zip is in Documents\Ahziael backups.

Changed: Uninstalling saves a backup first
Before it deletes anything, the uninstaller saves a full backup to Documents\Ahziael backups. Installing Ahziael again finds the newest backup and asks whether to bring everything back.
