Changed: Bot fixes go out by themselves
Every bot fix now goes out as a bot update as soon as it is ready, with no Ahziael update and nothing to press. The server picks it up within about ten minutes and restarts only the bots, after their battles end, while players stay online. A bot fix that also needed a change to the server waits for the next full update, so it can never break a server that does not have that change yet. Bot fixes now stay out of Ahziael's patch notes.
Where: Bots > Bot Updates
Test: Open Bot Updates and check that Live bot updates is on. After the next bot fix is merged, the page lists a new bot update within a few minutes and the bots log out and come back on their own.
