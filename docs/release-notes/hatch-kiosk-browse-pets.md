Fixed: Kiosk Browse Pets by Type and by Pedigree show the pets
Pressing Browse Pets by Type or Browse Pets by Pedigree at the Pet Hatching Kiosk did nothing, because the kiosk sent each pet in a form the game could not read. The kiosk now sends pets the way the game expects, so these pages, the talent search results, Friends' Pets and My Hatches show the pets and let you hatch with them.
Where: Any Pet Hatching Kiosk, Browse Pets window, no setting.
Test: Open Browse Pets, pick a pet type and press Browse Pets by Type, then press Browse Pets by Pedigree. Each one shows the kiosk's pets one by one with Hatch.
