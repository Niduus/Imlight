Fixed: Emperor's Retreat no longer locks you out after the towers
Going into a tower of the Emperor's Retreat threw away the main room behind you. The lever that the "Talk to Shalek" step unlocks after the tower bosses was unlocked in a room that no longer existed, so the door to the Frozen Lake never opened, and the tower bosses came back too. Now every room of a dungeon stays as it was while anyone is still inside the dungeon. Once everyone has left, it resets as before. This fixes other dungeons with side rooms the same way.
Test: Do the Emperor's Retreat in Krokotopia: beat both tower bosses, talk to Shalek, then pull the lever. The door should open.

Fixed: Dungeon quest steps put their levers and doors back when you come back
If a dungeon room was rebuilt after a quest step changed something in it (for example after logging out mid-dungeon), that change is now put back when you walk in, so the step can still be finished.
Test: In the Emperor's Retreat, after talking to Shalek about the lever, log out and back in, then check the lever can still be pulled.
