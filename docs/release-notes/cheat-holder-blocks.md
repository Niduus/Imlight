Added: Repeat and Only if blocks hold the blocks inside them
Repeat, the Only if blocks and the new Otherwise block used to ask how many blocks under them they meant. Now the blocks they work on sit indented inside them, closed by an end strip. Drop a block above the end strip to put it inside, or drag it below the strip to take it out, and the count keeps itself right. Moving or copying a holder takes its blocks along, and deleting one leaves its blocks in place.
Where: Player Cheats page and boss Cheats, on a cheat's Edit blocks page.
Test: Add a Repeat block, drag a Cast block above its end strip, and set it to 3 times. Press Try it: the cast shows three times.
