Fixed: Imported player cheats show without restarting Ahziael
Player cheats you imported from a share file on the Share tab did not show on the Player Cheats page until Ahziael was closed and opened again. Now the page reads the file again when you open it, so the imported cheats are there at once. If you had changes on that page you had not saved, Ahziael asks before showing the new list.
Where: Player Cheats page, after an import or Undo last import on the Share tab.
Test: Open Player Cheats, then go to Share and import a file with a player cheat in it. Go back to Player Cheats: the new cheat is in the list.
