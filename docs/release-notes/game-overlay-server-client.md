New: Server and Client parts of the overlay
The overlay designer now has two parts. "Client: my own" is your own texts and boxes, shown only on your game. "Server: everyone on my server" is what the host makes for every player on their server. Ahziael sends it to each player's overlay within a few seconds, no restart, and players can't hide it. Things are placed in a fixed order. The Ahziael line goes first, then the server's texts and boxes around it, and the player's own last. A player's own items are moved off the server's, so they never cover them.
Where: Play > Overlay > Design it (the two buttons above the picture)
Test: On the server PC, click "Server: everyone on my server", add a text, and drag it near the bottom-left corner. On a player's PC (or your own game), the text shows within a few seconds. Add a box of your own in the same place under "Client": it is moved off the server's text.

Changed: The Ahziael line can't be moved any more
"Ahziael made by Niduus | version" always sits in the bottom-left corner. It can't be moved, changed or turned off.
Where: Play > Overlay > Design it
Test: Pick "Ahziael line" in the list: there is nothing to change, and dragging it on the picture does nothing.

Changed: "Show my texts and boxes" stays on when the server needs the overlay
While the server you play on requires the overlay, the switch is on and greyed out.
Where: Play > Overlay > Game overlay
Test: On a server with "Require the Ahziael overlay" on, start the game with Play: the switch can't be turned off.
