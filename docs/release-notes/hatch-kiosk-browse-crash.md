Fixed: Browse Pets at the Pet Hatching Kiosk crashed the game
In 0.10.956, picking a pet type in Browse Pets closed the game, because the kiosk sent the pet in a form the game could not read. The kiosk sends pets the way it did before again, so the game no longer crashes.
Where: Any Pet Hatching Kiosk, Browse Pets window, no setting.
Test: Open Browse Pets, pick a pet type and press Browse Pets by Type. The game stays open.
