Fixed: A wizard who joined a battle just after it started had no pips
If you stepped onto a circle after the round had already begun (for example a second wizard running in right behind the first), you still played that round but got no pip for it, so a wizard with no pip gear had zero pips and could not cast anything. Now anyone who joins a round that has started, wizards and monsters alike, gets that round's pip right away, the same as everyone already in the battle.
Where: In the game, any battle someone joins after it started
Test: Log in two wizards. Start a battle with the first one, then walk the second one into the same battle as soon as the first round starts. The second wizard has 1 pip (or a power pip) in that first round instead of none, and can cast a 1 pip spell.
