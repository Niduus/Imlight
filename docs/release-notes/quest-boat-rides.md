Fixed: Quest boats and portals take you on
Some quest steps have you use a boat or portal, such as the dinghy at the Harbor in Polaris, but the server had no destination for it, so you stayed on the pier. Using one now takes you to the zone your next quest step is in. Every ride like this is written to the server log so it can be checked.
Where: quest boats and portals used as a quest step, starting with Polaris.
Test: on the Polaris quest that sends you out by the Harbor's dinghy, use the boat and check that you arrive where your quest arrow points.
