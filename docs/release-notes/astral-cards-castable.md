Fixed: Sun, Moon, Star and Shadow cards stayed grey with enough pips
A wizard who took an astral school with .astral could have plenty of power pips and still see that school's big cards greyed out, such as an 8 pip Shadow Efreet with 6 power pips. The game was shown a cost that still counted the wizard's school pips, which the game does not count for those spells. Now the game is shown a cost it can always see paid, and the server still takes the real cost.
Test: Take Shadow with .astral, get 4 or more power pips in a battle, and check an 8 pip Shadow card can be clicked and cast.
