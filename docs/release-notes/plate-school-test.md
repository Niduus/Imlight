New: A test switch for the missing school icon on battle name plates
The small school icon in the corner of every name plate in battle is empty since the Ahmarra update. This test switch sends the school to the game in a few different ways, so one battle shows which way the game wants. It's off (0) unless you change it.
Where: in the game's chat, .setting Battle PlateSchoolTest
Test: Type .setting Battle PlateSchoolTest 1 and start a new battle. Look at the corner of the name plates and take a screenshot. Do the same with 2, then with 3. Type .setting Battle PlateSchoolTest 0 when done.
