Added: Undo, Redo and Try it on the cheat editor
A cheat's edit page now has Undo and Redo buttons (Ctrl+Z and Ctrl+Y work too) for any change to its blocks until you leave the page. The Try it button walks through the cheat in a pretend fight and lists what would go off, in order, how many times, and what is skipped. Untick an If there to see what happens when it does not hold. Blocks that cannot work as they stand, such as a cast with no spell picked or an Otherwise in the wrong place, now show a yellow note.
Where: Player Cheats page and boss Cheats, on a cheat's Edit blocks page.
Test: Open a cheat, delete a block and press Undo: it comes back. Press Try it and untick one of its Ifs: the list says the cheat stops there.
