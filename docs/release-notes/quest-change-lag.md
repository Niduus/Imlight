Fixed: The game no longer lags after a quest changes something
When a quest turned one object on or off, the server sent your game every change your wizard ever had, from every world, so a wizard far into the game lagged after each quest. Now only that one change is sent, and only the changes for the area you are in go when you arrive.
Where: everywhere, most of all for wizards far into the game.
Test: on a wizard in a later world, finish a quest that opens a door or moves an NPC and check that the game does not freeze for a moment.
