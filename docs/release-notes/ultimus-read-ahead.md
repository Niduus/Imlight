New: Ultimus reads ahead before each world
When Ultimus starts a world's story, he reads the server's quest check for that world and lists every story step it says may not work yet on the Ultimus Issues page, marked READ-AHEAD, before he gets there. If the check is missing or older than a day, it is run again in the background first. He still tries every step as a player would, nothing is skipped.
Where: Ultimus Issues page, no setting.
Test: Let Ultimus start a new world (or restart the server). His log should say "READ-AHEAD" with what it found, and any problems show on the Issues page.
