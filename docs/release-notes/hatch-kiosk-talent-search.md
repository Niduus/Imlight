Fixed: Search Pet Talents at the Pet Hatching Kiosk finds pets
Searching the kiosk for pet talents stayed on "Please Wait - Searching Pets" forever, because the server answered with a message the game does not listen for. Now it answers the way the game expects. Search for all talents shows the pets at the kiosk that have every talent you picked, and Search for any of these talents shows the pets that have at least one, True Form's pets included.
Where: Any Pet Hatching Kiosk, Search Pet Talents window, no setting.
Test: Open a kiosk, open Search Pet Talents, pick Spell-Proof and click Search for any of these talents. The waiting box closes and pets with Spell-Proof show up.
