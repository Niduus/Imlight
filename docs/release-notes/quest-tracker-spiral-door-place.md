# Quest Tracker: the line leads to where the Spiral Door really is

Fixed: In the Commons, a quest in another world said "Way: Spiral Door to ..." but no line was drawn, because there is no Spiral Door in the Commons. The way now goes through Ravenwood to the Spiral Chamber, and the minimap line leads you there.
Changed: The server learns where the Spiral Door stands in each area you visit, so the way keeps getting more accurate in other worlds too.

Where: In the game overlay, use the Quest Tracker together with the Minimap.

Test:
1. Stand in the Commons and pick a quest in another world, for example "Face Your Fate" in Grizzleheim.
2. Check that the "Way:" line reads Ravenwood, then the Spiral Chamber, then the Spiral Door to Grizzleheim.
3. Check that the minimap line leads to the exit toward Ravenwood. Follow it to the Spiral Chamber; the line should then point at the Spiral Door.
