New: Ultimus and the Quest Team keep a gear set for every job

Ultimus and each Quest Team wizard now keep five gear sets in the game's Equipment Sets: Damage, Blading, Support, Healing and Questing. Each set uses the best gear they own for that job, and it is updated by itself when they get better gear. Every piece in a set is locked with the backpack padlock so it is never sold, and a piece no set uses any more is unlocked again.

Where: Ultimus and the Quest Team, their backpack and Equipment Sets.
Test: Let Ultimus play for a few minutes out of battle, then check his log for the line about saving his gear sets, and check that the gear in his sets shows a padlock and is never in his Quick Sell or shop sales.
