Fixed: Clicking "Find where to get this item" fast no longer disconnects you
Each fast click made the game ask the server the same question more and more times, hundreds a second, and the server's flood guard threw you out and then let you back in. The server now answers once per burst and ignores the extra copies, so you stay connected and the list still fills in.
