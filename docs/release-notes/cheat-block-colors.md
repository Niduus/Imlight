Added: Cheat blocks come in 13 colored groups
The cheat blocks used to be only four colors, with about 90 purple Do blocks in one long list. They are now split into colored groups with their own headings in the block list: When, Passive, Who, Limits, If, Cast, Hit and Heal, Effects, Pips and Cards, Battle, Show, Memory and Flow. Search still finds every block, and old cheats read the same.
Where: Player Cheats page and the Cheats part of a boss in Ahziael.
Test: Open a cheat with Edit blocks. The block list on the left shows the colored headings, and each block in the cheat has its group's color.
