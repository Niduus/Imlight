New: Bot Players (test stage)
Server-run wizards that look and act like players. This first test lets you call one bot next to you; it walks around, joins your battle when asked (it passes every round for now) and can be kicked from your battle. Bots run in their own small program, which only runs while Bot Players is on and is closed when you turn it off. Off by default.
Where: Game Rules > Battles and World
Test: Turn on Bot Players, go into the game and type .bot test. Start a battle, type .bot join and wait 5 seconds, then type .bot kick.

New: Bot Players log
Everything the bots do (appear, walk, join, pass, get kicked, leave) is written to its own log, in the server's logs\bot-players folder.
Where: Server > Logs
Test: After trying the bots, open Server > Logs and look at the Bot Players log card.

New: Bot Players buttons for the game overlay
An add-on with buttons for the bot commands: call a bot, join my battle, kick from battle, send away, and list.
Where: Play > Overlay
Test: Open Add-ons > Niduus's add-ons, download Bot Players, add the Bot buttons widget and click them in the game.
