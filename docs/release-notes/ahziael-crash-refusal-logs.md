New: Ahziael's crashes and refusals list
Every time Ahziael crashes, a tab can't open, something fails, Ahziael says no (the red line at the bottom), or the server stops by itself, it is written down and listed here, newest first. Click Details on a row to see everything. Search it, pick one kind, copy it, or make a zip to send.
Where: Server > Logs
Test: Open Server > Logs. Do something Ahziael refuses (for example, save a custom with no name) and watch it show up in the list.

New: Ahziael no longer vanishes when it can't open
If Ahziael can't open, it now writes down why and shows a message box with the reason instead of flashing in the taskbar and closing. When a newer version is out, it offers to update right there, so a broken version can't lock you out. Otherwise it offers to put the logs in a zip on your desktop to send in.
Test: Nothing to do unless it happens. If someone's Ahziael won't open, ask them for the message box text.

New: Safe start
If Ahziael closed while opening last time without being able to say why, it opens in safe start: the game overlay stays off until the next start, and a red line at the bottom says so. It is listed under Server > Logs as a crash.
Where: Server > Logs

Changed: one broken tab no longer stops Ahziael
If a single tab fails to build, that tab shows the reason in its own place and the rest of Ahziael opens as usual.
