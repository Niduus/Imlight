Fixed: Button words always show in full
A button's words used to get cut off when the button was smaller than them (a "Heal" button showed only "He"). Now the words shrink to fit the button, so the whole label always shows. A text given both a width and a height shrinks the same way. Words never grow bigger than the size you picked.
Where: Play > Overlay
Test: Make a button that says Heal, then drag its edge to make it small: the word gets smaller and stays whole.

New: Buttons for mob cheats and a list of commands
A button can now set off a mob (creature) cheat whose When is "it is pressed", in the battle of the wizard in that game window, as well as use one of your own player cheats. "Load mob cheats" lists the ones on the server. "Run an Imlight or Ahziael command" has a list of every command to pick from. As before, buttons only act for the wizard in their own game window, with no password.
Where: Play > Overlay
Test: Give a creature a cheat with When "it is pressed" and a name, make a button set to "Set off a mob (creature) cheat" with that name, then click it during a battle with that creature.
