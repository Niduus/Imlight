Fixed: Quest Arrow shows up and then disappears
On many quests the Quest Arrow popped up for a moment and then went invisible. Those quests have two or more steps in the same area, and the server could not tell the game which of its arrow spots belonged to which step, so the game found no spot and hid the arrow. The server now matches each step to the game's own step by its place in the quest, which gives an arrow to about 2,250 more quest steps across 720 quests, from Wizard City to the newest worlds.
Where: Every world, no setting.
Test: In Zafaria, take In The Cold Distance from Captain Bheki Blackhoof in the Savannah. The arrow should point to the fallen Watch Tower and stay, then point back to the Captain after the repair.
