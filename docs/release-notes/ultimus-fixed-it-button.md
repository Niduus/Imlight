New: Fixed it button on each broken quest
Each quest in the Broken quests list on the Ultimus Issues page now has a Fixed it button. Press it after you fix a quest: Ultimus forgets what went wrong there (the steps he set aside, his needs-help mark, lost fights and filed issues) and tries it again within a few seconds. The quest leaves the list and only comes back if it goes wrong again.
Where: Ahziael, Ultimus, Ultimus Issues, Broken quests, Fixed it.
Test: Press Fixed it on a quest in the list. It should disappear, and his log should say "FIXED, says Niduus" and he should go back to that quest.
