Fixed: Using the Storm Altar counts for Kraken Up
Using the Storm Altar in Storm Lord Temple did what the altar does but the "Kraken Up" step never counted, so the quest could not go on. Some quest objects have their own use as well as the quest's, and the click went only to the object's own use. Now a click on such an object also counts for the quest step of a wizard who needs it, as one press does in the live game.
Where: Storm Lord Temple in Celestia ("Kraken Up"), and any quest object with its own use besides the quest's.
Test: On "Kraken Up", use the Moon Dial, then go into Storm Lord Temple and use the Storm Altar; the step should tick off at once.
