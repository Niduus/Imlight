Fixed: Some quest steps showed an empty line on the quest page and the arrow read only "in"
A few "go to a place" steps, like the Bad Blood quest in Wizard City, came with no step text in the game files, so the quest page showed a blank goal and the quest arrow said just "in". The server now fills these steps in with the place's name, for every quest in every world that has the same gap.
Where: Quest page and quest arrow.
Test: Pick up Bad Blood in Wizard City. The quest page shows where to go and the arrow names the place.
