New: A switch that turns the whole game overlay off

Ahziael now has a Game overlay switch that turns its overlay off completely. While it is off, nothing at all is drawn on the Wizard101 window: no Ahziael line, no buttons, no add-ons and no sparkle button, and the overlay keeps no link to the server. It works right away without a restart, Ahziael Overlay on its own follows it too, and it starts on like before. A server that requires the overlay will disconnect you while it is off.

Where: Ahziael, Play tab, Overlay, the first switch in Game overlay.
Test: With Wizard101 open, turn Game overlay off. Everything Ahziael draws on the game should go within a second. Turn it back on and it should come back within a second.
