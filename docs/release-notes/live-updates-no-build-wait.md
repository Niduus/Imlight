Fixed: Updates with Live patches on still made you wait for a build and a restart
With Live patches on, an update's fixes now go into the running server as soon as the update is downloaded, before anything is built, so nobody waits and nobody is disconnected. The build still runs afterwards at low priority, so the game and the server stay smooth, and its files go in quietly the next time the server starts on its own. Updates that answer a new kind of game message, like the Friendly Players quest list, now work without a restart. Updates that add a new setting with a starting value, like 0.10.956 and 0.10.961 did, also go in without a restart.
Where: Update Ahziael with the Live patches switch on at the top of the window
Test: With Live patches on and the server running, click Update Ahziael for the next update after this one. Within a minute Ahziael says the update's fixes are in the running server, while it is still building in the background, and nobody in the game is disconnected.
