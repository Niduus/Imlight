Fixed: The overlay on the game didn't match the designer's picture
The designer's picture was always 1280 x 720, so on a bigger or differently shaped game window, texts and boxes landed somewhere else and at another size. Now the design grows and shrinks with each game window and keeps to its corner or side. So it looks as you set it up on every game window, even with several open at different sizes. This includes the server's part. Texts and boxes can't go outside the game window. A piece you drag is pinned to the corner or side you dropped it nearest to.
Where: Play > Overlay > Design it
Test: Open the game in a window, then in "Design it" pick "Game window 1" under Picture size (it's picked for you while the game is open). Drag a box to the top left. On the game it shows at the top left too, at the same size compared with the window. Make the game window bigger: the box grows with it and stays top left.

New: Change the overlay right on the game
Clicking the sparkle button on the game now opens the designer right on the game window. The game gets a little darker, and a bar shows at the top. Click a text or box to pick it, drag it to move it, drag its right or bottom edge to size it, or drag "Text" or "Box" onto the game to add one. You can change the words of the picked text, remove it, or switch between Client and Server. "Full designer" opens Ahziael's designer for fonts, colours and the rest. "Done" (or Esc) goes back to playing. Both designers change the same design and follow each other.
Where: The sparkle button in the game's bottom-right corner
Test: Click the sparkle button, drag "Box" onto the game, move it, and click Done. The box stays. Open Play > Overlay in Ahziael: the box is there too.
