Fixed: Gates, walls and bridges open when the quest step that works them is done
Many later-world quests left a gate shut, a bridge up or an invisible wall in place after you finished the step that should open it, such as the Basstille gate after Use the Key and New Blago's bridge after the control room lever. The server now opens the gate or lowers the bridge and takes the wall away for you when that step is done, and keeps it open after a log-in. Every one of these is written to the server log so it can be checked.
Where: every world, most of all Polaris and the later worlds.
Test: finish Use the Key at the Basstille and walk through the gate, then pull the lever in New Blago's control room and cross the bridge in Forlorn Taiga.
