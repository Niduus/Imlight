New: Shorter, grouped overlay menu on the game
The edit menu that shows on the game while you change the overlay is now smaller and sorted into small labeled groups, so each tool is easy to find. Adding text, boxes and buttons sits together, the rarer pieces sit under More, and the new Plugins list lets you pick a piece from your add-ons and put it on or take it off right there. Grid and snap switches and the picked piece's Remove button each have their own group too.
Where: In game, open the overlay edit menu.
Test: Open the edit menu on the game, check the groups read Overlay, Add, Plugins, Picked, Grid and More, then pick a plugin piece, press Put on, and see it appear on the game.
