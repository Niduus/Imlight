Added: Otherwise and Stop cheat blocks
Two new Flow blocks are available. Otherwise goes right under an Only if block and runs its own blocks only when that Only if said no, such as only if rage is at least 5 then enrage, otherwise add 1 rage. Stop ends the cheat's blocks there for this time. Both work in player cheats and boss cheats. A block you turn off now also keeps its place, so the blocks inside a Repeat or Only if stay the right ones.
Where: Flow group in the cheat block list.
Test: Make a cheat with Only if variable rage at least 5 holding a Say, then Otherwise holding Set variable rage add 1. Fight: the first rounds add rage, and the line shows once rage reaches 5.
