Fixed: Ultimus and the Quest Team answer "where is" with places from the game's own files
When a player named a person in chat and the answer came from the AI, the AI answered from its own memory of Wizard101 and could get the place wrong. Now Ultimus and each Quest Team wizard hand the AI where the game's own files place that person, up to four areas each, so the answer uses the real places. Two new self-test checks also guard today's Bazaar trip fix and the fix for creatures that start no battle, so those bugs are caught if they ever come back.
Where: Ultimus and Quest Team chat with the AI turned on; Ultimus self-test.
Test: With the AI on, ask Freya or Ultimus "where is Watson?"; the answer should name Scotland Yard's roof and Katz's lab, the places the game puts the two Watsons.
