Fixed: Kiosk Browse Pets and talent search open the hatch window
Pressing Browse Pets by Type or by Pedigree, or finding a pet with Search Pet Talents, never opened the window with your pet and the kiosk pet side by side. The game wants only the pet's own details for that window, and the kiosk sent the whole pet. Now it sends just the details, so the window opens with the kiosk's pet on the right.
Where: Any Pet Hatching Kiosk, Browse Pets and Search Pet Talents, no setting.
Test: Open Browse Pets, pick a type and press Browse Pets by Type, then try Browse Pets by Pedigree and a talent search that finds a pet. The two-pet hatch window opens each time and the game stays open.
