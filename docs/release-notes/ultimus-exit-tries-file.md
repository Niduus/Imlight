New: Ultimus writes down where he stood at a door that didn't work

When a walk-through door still doesn't take Ultimus after a full round of tries, he now writes each try into exit-tries.txt in his logs folder. It shows where he stood, how far he was from the door's middle, and where he walked out and back in. One file is enough to fix that door, and it is also included in "Copy all logs".

Where: Ultimus, exit-tries.txt in his logs folder, and Ahziael's Copy all logs button.
Test: If his log shows a pink line saying a door "never took it on", open exit-tries.txt. It should list each try for that door.
