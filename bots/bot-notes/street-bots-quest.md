New: Street bots that quest like the TCO7
Up to 30 street bots can now play the Main Story the way the TCO7 do, each with Ultimus's brain, the same quest rules and the same shared knowledge, so every one of them learns from all the others. Each gets a plain random name from the game's own name lists and the schools are taken in turn. Now and then, where a way past a stuck spot is already known, a street bot tries a different safe move first, so the bots learn more than one way past each spot, and what failed is written down as well as what worked. Turn them on with .streetbots on 6 in the game chat (any number up to 30), change how many with .streetbots 10, see them with .streetbots, and turn them off with .streetbots off. Changes work within seconds, without a restart.
Where: Every Main Story world; their logs are in the server's logs\street-questers folder.
Test: Type .streetbots on 3, wait a minute, then .streetbots: three bots should show, starting at level 1 in Wizard City. .ultimus tp and a bot's name takes you to it. .streetbots off logs them out.
