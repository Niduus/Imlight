Let Hellhound update itself

Hellhound's updates live in your private bots repo, so it needs a read-only key once. It stays on this PC.

  1. Open github.com/settings/personal-access-tokens/new (signed in as Niduus).
  2. Token name: Hellhound. Expiration: No expiration (or the longest offered).
  3. Repository access: Only select repositories, then pick ahziael-bots.
  4. Permissions: Repository permissions, then Contents: Read-only. Leave everything else as it is.
  5. Click Generate token, copy it, and paste it here:
