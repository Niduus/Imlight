# About the Hive mind

The Hive mind is what the questing bots know about getting the story done: Ultimus, the seven TCO7 wizards, the Kitharas Family and the Quest Team. They all share one brain, so a lesson one of them learns is known by all of them. Ahziael shows these pages on its Hive mind tab, and checks this folder on GitHub when it opens, when the server starts and every 30 minutes, so a page changed here shows in Ahziael without an update.

Zoom (the story scout) and True Form keep their own data. They teleport, one-shot or play at any level, so nothing they do is taken into the shared brain or these pages. Zoom's own findings (broken quests, boss cheats) are on his own page in Ahziael.

## What is in this folder
- How the bots quest: the rules every bot follows on a quest.
- How the bots fight: which way of fighting wins for each kind of fight, from every questing bot's fights.
- Quest corrections: every fix the bots were given for a quest, a dungeon or a puzzle, by world and place.
- What every bot learned from True Form: the gear, jewel, pet and order rules Niduus set while testing True Form, which hold for every bot.
- Bot Update rounds: what each quarter-hour Bot Update round saw and shipped, oldest first.
- Bot results: one page per world, built from the server log after each bots update and kept for good: the best way to beat each creature, every quest finished, the fastest wins, and the fights lost and places stuck to avoid. Solo means the bot fought alone; Team means another of our bots was in the same battle.

## How sure it is
- How the bots fight and Bot results are counted from the bots' own logs.
- Quest corrections and Bot Update rounds are written each round and can hold notes that are still being looked into; those say so.

## Your own server
The Hive mind tab also collects the same kind of facts from the bots on your own server, each time the server starts. That part stays on your computer.
