# Niduus's overlay add-ons

Every overlay add-on (`.ahziaeladdon` file) in this folder shows up in Ahziael under
**Play > Overlay > Add-ons > Niduus's add-ons**, with a **Download** button.

To put up a new one:

1. In Ahziael, make it in the overlay designer, then click **Make an add-on from my design** and save the file.
2. Give the file to Claude in the Imlight project (or upload it into this folder on GitHub, on the page whose header
   says "Niduus / Imlight").

To update one, keep its **Name** the same and raise its **Version** (1, 2, 3...). Players who already have it then see
**Get the newer one**.

Add-ons are only data (words, colours, numbers and pictures). Ahziael checks every one the same way as an add-on file,
so nothing in them can run.
